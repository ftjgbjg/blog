🎵 音乐笔记

2026-01-04 4 min read # 随便写写

🎵 听 · 音乐拾遗

“ 所有的情绪，都有对应的旋律 ”
“ 仅代表个人见解，不喜勿喷 ”

✨ —————— · 🎧 · —————— ✨

🎸 金玟岐

  • 作品： 💿 《完美世界》 / 💿 《大七电台》 / 🎵 《天真有害》

心动瞬间： “你我都并没有错，只是天真有害，想得太美，才让现实有机可乘。”
听感： > * 《完美世界》：在支离破碎的现实里构建的一场美梦，是每个极客内心最柔软的避风港。

  • 《大七电台》：充满都市气息的深夜电台感，非常适合在写代码或折腾域名时作为背景。
  • 《天真有害》：那是对天真最清醒的告白。大七的词总是这样，外表粉色少女，内核硬核清醒。

🎤 milet

  • 作品： 💿 《eyes》 / 《visions》 / 《5am》/ 《milet live at 日本武道館》

听感： 力量与柔情的平衡点，厚实的欧美嗓在日系旋律里非常有辨识度。

🌹 陈一发儿

  • 作品： 🎵 《弦上有春秋》 / 🎵 《白山茶》 / 🎵 《童话镇》

听感： 好听，爱听。

🎹 徐佳莹

  • 作品： 💿 《心里学》 / 《LaLa首张创作专辑》

心动瞬间： 那些关于自我剖析的歌词。
听感： 细腻入微，像是在深夜里进行的一场心理咨询，温润但有力量。

🎙️ 邓紫棋 (G.E.M.)

  • 作品： 💿 《摩天动物园》 / 《启示录》 / 《新的心跳》 / 《T.I.M.E.》

听感： 她的声音有一种不容置疑的掌控力。无论是在录音室还是现场，那种穿透灵魂的共鸣感非常惊艳。

🦋 唱功天花板

  • 推荐： 黄霄云 💿 《没语季节》 / 🎵 《打开》 / 🎵 《星辰大海》 / 李佳薇 🎵 《煎熬》 / 🎵 《天后》 / 🎵 《大火》 / 🎵 《炼爱》 / 🎵 《别来无恙》

听感： 唱功天花板级别的存在。高音的稳定度和情感的张力，让这些大歌听起来极具冲击力。

🕊️ 咻咻满

  • 作品： 🎵 《慢慢喜欢你》 / 🎵 《烟火赴新年》 / 🎵 《驯服夜的光》

心动瞬间： 灵动、自由且不设限的嗓音。
听感： 自由感拉满，翻唱也总能赋予歌曲全新的灵魂。

🌫️ 二五吸烟所 (25 Smoking Station)

  • 作品： 💿 《光明路》 / 🎵 《末路》/ 💿 《夢醒記》 / 🎵 《柒岛》

听感： 属于深夜的忧郁和诗意。他们的音乐里有一种独特的城市颓废感和微醺的氛围，像是一支在雨夜街头缓缓点燃的烟，适合一个人静静地循环。

🍭 初音未来 (Hatsune Miku)

  • 作品： 🎵 《ハローセカイ》 / 🎵 《ブループラネット》 / 🎵 《Air》

听感： 跨越次元的情绪共振。电子声线里承载着无数人的青春和创作热诚，这种纯粹的表达感不可替代。

🎻 现代器乐 (Neoclassical / Jazz)

  • Cicada： 💿 《Over the Sea / Under the Water》 / 💿 《Pieces》 / 🎵 《抵达圈谷之前的棱线》 / 🎵 《降落在金黄色草坡》
  • Gogo Penguin： 💿 《v2.0》 / 💿 《Everything Is Going to Be OK》

听感： Cicada 像海浪般的室内乐，画面感极强；Gogo Penguin 是极具现代感的钢琴爵士，像是在大脑里跳舞。

🌌 后摇 / 器乐摇滚 (Post-Rock)

  • Lights & Motion： 💿 《Dear Avalanche》 / 💿 《Reanimation》 / 🎵 《Light My Fire》
  • Fayzz： 💿 《Connection》 / 💿 《Days gone》 / 💿 《Patch》

听感： Lights & Motion 大气磅礴，仿佛置身星辰大海；Fayzz 细腻且有逻辑，让思绪随旋律飞翔。

🎸 电子核 / 另类摇滚 (Electronicore / Alternative Rock)

  • Bring Me The Horizon： 🎵 《Can You Feel My Heart》

听感： **标志性的切分音采样带来极强的破碎感与工业张力，在汹涌的嘶吼与宏大的合成器背后，隐藏着极致的孤独与自我挣扎。尤其是末尾处的情绪变奏，人声从克制的询问演变为绝望的嘶吼，最终在最稠密的音墙中戛然而止，仿佛一场在废墟中爆发后又迅速沉寂的内心海啸。

💃 张惠妹

  • 作品： 🎵 《彩虹》 / 🎵《连名带姓》

听感： 歌后级的情感掌控力。每一首歌都是在用生命讲故事，越听越有味道。
